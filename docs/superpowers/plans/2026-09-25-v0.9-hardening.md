# execkit v0.9 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make execkit sessions survive everyday agent commands, close the security gaps found in the 2026-09-25 review, improve the agent-facing MCP surface, and fix docs/distribution, shipped as v0.9.0.

**Architecture:** The core fix replaces the one-line `{ cmd ; }` framing with a base64-chunked payload that is `eval`'d in the current shell, with fresh per-command sentinel tokens, stdin closed, and interrupt-then-resync on timeout instead of poisoning. Security, MCP and docs work layer on top without changing that protocol.

**Tech Stack:** Rust 1.88 workspace (`execkit` core, `execkit-mcp` rmcp 1.7 server, `execkit-py` PyO3), portable-pty, russh 0.61, schemars 1.

- Target hosts must have `base64` (coreutils or busybox). If missing, `session_create` fails with: `execkit needs 'base64' on the target shell (coreutils or busybox)`.

## Review Focus

1. Commands containing tabs, `\r`, `^C`/`^U`/`^D` bytes, non-UTF-8-safe unicode, or > 4 KB of text must run verbatim (a PTY line discipline or readline must never see raw command bytes). Test in Task 1.
2. POSIX `sh` semantics: a syntax error inside `eval` must not exit dash/busybox, and `base64 -d` must work there. Test in Task 1 with `sh -i` (dash) and in docker (busybox).
3. `set -e` followed by a failing command exits the shell; the agent must get a clear "shell exited" error naming `exit`/`set -e`, and the MCP server must drop the dead session. Test in Task 4.
4. Timeout interplay: a timed-out command that ignores SIGINT must end in a poisoned (and, in MCP, auto-destroyed) session, never a desynced one. Test in Task 2.
5. Large output with a budget (e.g. `seq 1 200000` + `keep tail 3`) must report the true `lines_total` and let grep see the middle. Test in Task 3.

## Phase A: sessions that survive real commands

### Task 1: Framing protocol rework

Fixes: `# comment`, trailing `&`, heredocs, `!` history expansion, syntax errors, unclosed quotes, `history`, tabs/control bytes, > 4 KB lines on sh PTYs, stdin-reading commands hanging, commands written to `~/.bash_history`, `set -x` leaking framing, and marker forgery via the token in the stderr file name.

**Files:**
- Create: `crates/execkit/src/framing.rs`
- Modify: `crates/execkit/src/lib.rs` (add `mod framing;`), `crates/execkit/src/transport/mod.rs:30-53`, `crates/execkit/src/session.rs:24-105, 474-591`
- Test: `crates/execkit/src/framing.rs` (unit), `crates/execkit/tests/framing_robust.rs` (new, real PTY)

**Interfaces:**
- Produces (`framing.rs`, `pub(crate)`):
  - `fn new_token() -> String`: 32 hex chars from `/dev/urandom` (move `unique_token`'s randomness here; keep `session::unique_token` for checkpoints/docker, delegating to it).
  - `struct Markers { pub start: String, pub end: String }` with `fn Markers::new(token: &str)` -> `start = "__EXECKIT_{token}__"`, `end = "__EXECKITEND_{token}__"`.
  - `fn build_payload(command: &str, token: &str) -> String`
  - `fn parse(acc: &[u8], m: &Markers) -> Option<Parsed>` where `struct Parsed { pub stdout: String, pub stderr: String, pub exit_code: i32, pub cwd: String }` (fields already `clean()`ed).
- `transport::shell_init` keeps its signature and additionally sets up history-off and the `__ek_d` decoder variable.

**Protocol (exact):**

`shell_init` sends (one line; must stay < 1 KB):
```sh
stty -echo 2>/dev/null; PS1=''; PS2=''; PROMPT_COMMAND=''; set +o history 2>/dev/null; set +H 2>/dev/null; unset HISTFILE; if printf 'YQ==' | base64 -d >/dev/null 2>&1; then __ek_d='base64 -d'; elif printf 'YQ==' | base64 -D >/dev/null 2>&1; then __ek_d='base64 -D'; else __ek_d=''; fi; printf '%s\n' EXECKITrdy''9f3a7c"${__ek_d:+ok}"''
```
Readiness: output contains `EXECKITrdy9f3a7cok` -> ready. Output contains `EXECKITrdy9f3a7c` followed by a newline and NOT `ok` -> `Err(Error::Transport("execkit needs 'base64' on the target shell (coreutils or busybox)".into()))`. (The `''` pairs keep the echoed input from matching, as today.)

Also spawn local bash with `HISTFILE` removed from its environment: in `Session::local()` use `LocalPty::spawn_with_env("bash", &["--norc", "--noprofile"], &[("HISTFILE", None)])`, adding an `env_remove` capability to `LocalPty` (portable-pty `CommandBuilder::env_remove`).

`build_payload(command, token)` returns, joined with `\n` and ending in `\n`:
1. `{ __ek_c=''; } 2>/dev/null`
2. For each chunk of the base64 of `command` (standard alphabet, `=` padding, chunk size 760 chars): `{ __ek_c="${__ek_c}<chunk>"; } 2>/dev/null`
3. The run line (single line, no raw command bytes):
```sh
{ __ek_f=$(mktemp 2>/dev/null || printf '%s' "${TMPDIR:-/tmp}/execkitE_$$_<token8>"); : > "$__ek_f"; chmod 600 "$__ek_f"; } 2>/dev/null; { eval "$(printf '%s' "$__ek_c" | $__ek_d)"; } </dev/null 2>"$__ek_f"; { __ek_rc=$?; printf '\n%s\037%d\037%s\037' '<START>' "$__ek_rc" "$(printf %s "$PWD" | tr -d '\037')"; cat "$__ek_f"; rm -f "$__ek_f"; unset __ek_c __ek_f; printf '%s\n' '<END>'; } 2>/dev/null
```
where `<START>`/`<END>` are `Markers::new(token)` and `<token8>` is the first 8 chars of the token. The tokens appear only in this line, which the shell has fully read before the command runs, so a child process cannot read them from the tty. The stderr file name is random (mktemp) and unrelated to the token. The `{ ...; } 2>/dev/null` wrappers keep `set -x` traces of the framing out of the output while the user's own trace still goes to their stderr.

`parse(acc, m)`: find the **first** `m.end`; then the **last** `m.start` before it (`rfind`); require three US (0x1f) separators between them as today; `stdout = acc[..start_pos]` with exactly one trailing `\n` (the one the trailer's `printf '\n...'` added) removed before `clean()`; exit code parse failure -> `-1`.

`Session` changes: drop the cached `start_m/end_m/errfile` fields; `run_framed` calls `framing::new_token()` per command, writes `build_payload`, and loops on `framing::parse`. Keep the anti-flood compaction exactly as-is in this task (Task 3 changes it).

- Consumes: Task 1 `framing::{new_token, build_payload, parse, Markers}`.
- Produces:
  - `ExecResult.timed_out: bool` (`#[serde(default)]`, serialized always).
  - `Session::set_timeout(&mut self, d: Duration)` (non-consuming; `with_timeout` stays).
  - `Session::exec_with_timeout(&mut self, command: &str, budget: Option<&Budget>, timeout: Duration) -> Result<ExecResult>`; `exec`/`exec_budgeted` delegate to it with the session timeout.
  - Error texts: `StillRunning` -> `"command timed out and could not be interrupted; the session was closed - create a new session"`; `SessionPoisoned` -> `"session is no longer usable (a command could not be interrupted, or the shell exited); create a new session"`. **Behaviour:** when the deadline passes, write `\x03` to the transport, then run a resync: new token, `build_payload("rm -f \"$__ek_f\" 2>/dev/null; unset __ek_c __ek_f", token)` (cleans the interrupted command's stderr temp file), wait up to 5 s for its end marker (discard everything before its start marker). On success, return `Ok(ExecResult { exit_code: 124, timed_out: true, stdout: <output captured before the interrupt, cleaned>, stderr: "execkit: timed out after {secs}s; sent Ctrl-C. The shell session is intact (cwd/env kept). For long jobs run them in the background: nohup CMD > /tmp/job.log 2>&1 & then poll the log.", .. })`, passed through the same redact/budget/audit path as a normal result. If the resync fails, poison and return `Err(Error::StillRunning)`.
